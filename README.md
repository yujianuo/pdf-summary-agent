 # PDF Multi-Agent Analyzer

## 1. 프로젝트 개요
본 프로젝트는 PDF 문서를 업로드하면 여러 개의 서브 에이전트가 협력하여 문서 내용을 분석하는 멀티 에이전트 시스템이다.  
단순히 문서를 한 번에 요약하는 방식이 아니라, 각 에이전트가 서로 다른 역할을 맡아 문서 구조 분석, 내용 요약, 핵심 정보 추출을 수행한 뒤 최종 결과를 통합하는 방식으로 설계하였다.

이 프로젝트의 주된 목적은 긴 PDF 문서를 사용자가 직접 모두 읽지 않더라도 핵심 내용을 빠르게 파악할 수 있도록 돕는 것이다.  
또한 이번 과제를 통해 Deep Agents 기반의 멀티 에이전트 구조를 직접 구현하고, 여러 서브 에이전트가 협력하는 방식의 동작 원리를 이해하는 것을 목표로 하였다.

---

## 2. 프로젝트 목표
이 프로젝트의 목표는 다음과 같다.

1. 사용자가 업로드한 PDF 파일에서 텍스트를 추출한다.  
2. 추출된 텍스트를 바탕으로 문서의 주제와 구조를 파악한다.  
3. 문서 전체 내용을 요약한다.  
4. 핵심 키워드와 중요한 문장을 추출한다.  
5. 여러 에이전트가 협력하여 최종 분석 결과를 생성한다.  

즉, 이 시스템은 단순 요약기가 아니라 **문서 분석을 위한 멀티 에이전트 팀**으로 동작하도록 설계되었다.

---

## 3. 에이전트 구조
본 시스템은 총 4개의 에이전트 구조로 이루어져 있다.

### 3.1 Supervisor Agent
Supervisor Agent는 전체 작업을 관리하는 메인 에이전트이다.  
사용자가 PDF를 업로드하면 전체 흐름을 계획하고, 각 서브 에이전트에게 적절한 작업을 분배한 뒤 결과를 취합하여 최종 출력 형태로 정리한다.

주요 역할:
- 전체 작업 계획 수립
- 서브 에이전트에게 작업 분배
- 각 에이전트 결과 통합
- 최종 결과 생성

### 3.2 Reader Agent
Reader Agent는 PDF에서 추출된 텍스트를 읽고 문서의 주제와 전체 구조를 파악하는 역할을 한다.  
문서가 어떤 내용을 다루는지, 어떤 흐름으로 구성되어 있는지를 정리하여 이후 분석 과정의 기반 정보를 제공한다.

주요 역할:
- 문서 주제 파악
- 문서 구조 분석
- 주요 섹션 정리

### 3.3 Summary Agent
Summary Agent는 문서 전체 내용을 요약하는 역할을 담당한다.  
짧은 요약과 함께 보다 자세한 요약을 생성하여 사용자가 문서 핵심을 빠르게 이해할 수 있도록 한다.

주요 역할:
- 전체 내용 짧은 요약
- 상세 요약 생성
- 핵심 아이디어 정리

### 3.4 Insight Agent
Insight Agent는 문서 안에서 중요한 정보들을 추출하는 역할을 한다.  
핵심 키워드, 중요한 문장, 학습 포인트 및 주요 시사점을 정리하여 보다 구조적인 분석 결과를 제공한다.

주요 역할:
- 핵심 키워드 추출
- 중요한 문장 추출
- 주요 내용 및 시사점 정리

---

## 4. 시스템 동작 원리
이 시스템의 전체 동작 과정은 다음과 같다.

1. 사용자가 Streamlit 웹 페이지에서 PDF 파일을 업로드한다.  
2. 시스템이 `PyPDF2`를 사용하여 PDF 내부의 텍스트를 추출한다.  
3. 추출된 텍스트를 정리하여 분석 가능한 형태로 전처리한다.  
4. Supervisor Agent가 작업 계획을 세운다.  
5. Reader Agent가 문서 주제와 구조를 분석한다.  
6. Summary Agent가 문서 내용을 요약한다.  
7. Insight Agent가 키워드, 중요한 문장, 주요 내용을 추출한다.  
8. Supervisor Agent가 각 결과를 통합하여 최종 분석 결과를 생성한다.  

최종적으로 사용자에게는 다음 네 가지 형식으로 결과가 출력된다.

- 전체 요약
- 핵심 키워드
- 중요한 문장
- 주요 내용 정리

## 5. 구현 환경 및 사용 기술
본 프로젝트는 다음 기술을 사용하여 구현하였다.

- **Python**: 전체 시스템 구현
- **Streamlit**: 사용자 인터페이스 구현
- **PyPDF2**: PDF 텍스트 추출
- **Deep Agents**: 멀티 에이전트 구조 구현
- **LangChain**: 에이전트 생성 및 모델 연결
- **Gemini API**: 문서 분석 및 요약 수행

```bash

###

python3 -m pip install -r requirements.txt

웹 페이지에서 PDF 파일을 업로드한다.

이를 통해 API 사용이 제한된 상황에서도 최소한의 분석 결과를 확인할 수 있도록 하였다.
9. 프로젝트 특징 및 장점
이 프로젝트의 특징은 다음과 같다.
단일 에이전트가 아니라 여러 서브 에이전트가 협력하는 구조를 사용하였다.
PDF 문서 분석 과정을 역할별로 분리하여 보다 명확한 작업 흐름을 만들었다.
긴 문서를 사용자가 직접 모두 읽지 않아도 핵심 내용을 빠르게 파악할 수 있다.
Deep Agents 구조를 통해 멀티 에이전트 시스템의 개념을 실제로 구현해 볼 수 있었다.
10. 한계점
본 프로젝트에는 다음과 같은 한계가 있다.
PDF가 이미지 기반 스캔본일 경우 텍스트 추출 성능이 떨어질 수 있다.
Gemini API quota 또는 네트워크 상태에 따라 성능이 달라질 수 있다.
현재는 긴 문서 전체가 아니라 일부 텍스트만 잘라서 분석하도록 제한한 부분이 있다.
문서 유형에 따라 분석 결과의 정확도가 달라질 수 있다.
11. 향후 개선 방향
향후에는 다음과 같은 방향으로 확장할 수 있다.
OCR 기능을 추가하여 이미지형 PDF도 분석 가능하도록 개선
문서 전체를 여러 chunk로 나누어 더 정교한 분석 수행
표, 그림, 수식 등 비텍스트 요소 분석 기능 추가
요약 결과를 PPT 또는 보고서 형식으로 자동 변환하는 기능 확장
12. 결론
본 프로젝트는 PDF 문서를 자동으로 분석하는 멀티 에이전트 시스템을 구현한 것이다.
Reader Agent, Summary Agent, Insight Agent가 각각 역할을 수행하고, Supervisor Agent가 이를 통합하여 최종 결과를 생성하도록 설계하였다.
이를 통해 단순한 PDF 요약 기능을 넘어서, 여러 에이전트가 협력하는 구조적 문서 분석 시스템을 구현할 수 있었으며, Deep Agents 기반 멀티 에이전트 시스템의 활용 가능성을 확인할 수 있었다.
